# ファミ旅プランナー

家族向けの旅行プランを提案するWebアプリです。

出発地、旅行日数、移動手段、家族構成、予算、旅行の目的などを入力すると、子連れでも無理のない旅行プランを提案します。

## 目的

このアプリは、家族旅行の計画を立てるときに発生する悩みを減らすことを目的としています。

* 行き先が決まらない
* 子ども連れで無理のない行程にしたい
* 移動時間を考慮したい
* 休憩場所も含めて考えたい
* 温泉、自然、動物、海、食事など家族に合った目的で探したい
* 知らなかった旅行先も見つけたい

単なる観光地検索ではなく、実際に家族で行きやすい旅行プランを作ることを目指します。

## 最初の機能

初期版では、以下の入力項目をもとに旅行プランを作成します。

* 出発地
* 旅行日数
* 移動手段
* 家族構成
* 子どもの年齢
* 優先したい目的
* 予算
* 片道の移動許容時間

## 提案される内容

入力内容に応じて、以下のような旅行プランを表示します。

* おすすめエリア
* 旅行コンセプト
* 1日目、2日目のざっくり旅程
* 子連れ向けの休憩ポイント
* 食事候補
* 注意点
* このプランが向いている家族

## 初期開発方針

まずはスマホで使いやすいシンプルなWebアプリとして作成します。

初期版では、外部APIや予約機能は使わず、入力内容に応じてサンプルデータから旅行プランを表示する形にします。

将来的には、AIによる旅行相談、天気情報、地図連携、宿泊候補の提案などを追加する予定です。

## 技術構成

初期版は以下の構成を想定しています。

* HTML
* CSS
* JavaScript

まずは静的なWebアプリとして作り、GitHub Pagesなどでスマホから確認できる形を目指します。

## 今後追加したい機能

* AIによる旅行プラン自動生成
* Googleマップ連携
* 天気情報の表示
* 宿泊候補の提案
* 子連れ向けスポットデータの追加
* 旅行プランの保存
* 複数プランの比較
* 雨の日プランの提案
* 予算別プランの提案

## 開発ステップ

1. 入力フォームを作る
2. サンプル旅行プランを用意する
3. 条件に合うプランを表示する
4. スマホで見やすい画面に整える
5. GitHub Pagesで公開する
6. AI連携や地図連携を検討する
